*** ~org-roam-db-sync~
Rebuilds the cache manually to re-index for searching, etc.

Use this after a pull from the notes git repo. The
~org-roam-db-autosync-mode~ function is called in the Emacs init so a
restart would accomplish the same thing.

*** ~org-roam-node-insert~

Inserts a new node.

*** ~org-roam-node-find~

Either finds or inserts a new node.

*** ~org-id-get-create~

Creates an id for a top-level header that makes the header into a node.

** Actions
*** Find or create a note
Use this when you think of a new note when not already in Org Roam context.

M-x org-roam-node-find (C-c n f)

*** Find or create a new note and link at point
Use this when editing a note and think of a new note and want to create and link to the new note from the current note.

M-x org-roam-node-insert (C-c n i)

*** Visit an note link
Use this to visit a note linked in the current note.

M-x org-open-at-point (C-c C-o)

** Notes

*** Using spaces in minibuffer
The space bar is mapped to completion in the minibuffer so when
creating or searching for nodes containing spaces, use ~C-q <space>~
to insert a space.

** Multiple stores
*** Each store needs its own database
Setting ~org-roam-directory~ alone is not enough. ~org-roam-db-location~
keeps its default under =~/.emacs.d/=, so a second store silently reads
the first store's cache. ~agg--roam-switch~ sets both, which is why it
exists instead of a bare ~setq~ of the directory.

At startup the config calls ~(agg--roam-switch org-roam-directory t)~:
=custom.el= owns which store loads, and this fixes only the half that has
no per-machine setting.

*** Commands
| ~agg/roam-toggle-notes~             | toggle between work and personal |
| ~agg/roam-switch-to-personal-notes~ | go to personal                   |
| ~agg/roam-switch-to-work-notes~     | go to work                       |

These are defined at top level rather than inside ~use-package~'s
~:config~ so they exist from a cold session -- ~agg--roam-switch~ requires
org-roam itself.

The toggle is deliberately asymmetric: from the work notes it goes to
personal, and from *anywhere else* -- including an ~org-roam-directory~ it
does not recognize -- it goes to work. So a stray value resolves to the
startup default instead of leaving you stuck. Comparison is by
~file-truename~ with normalized trailing slashes, so a symlinked path still
matches.

*** Syncing a store you are not currently in
~org-roam-db-sync~ reads ~org-roam-directory~ and ~org-roam-db-location~
dynamically, and ~org-roam-db--connection~ is a hash keyed by directory
which ~db-sync~ closes first to force a reconnect. So a ~let~ binding
reindexes the *other* store without disturbing the current session:

#+begin_src emacs-lisp
  (let ((org-roam-directory "~/notes/")
        (org-roam-db-location "~/notes/org-roam.db"))
    (org-roam-db-sync))
#+end_src

Calling ~agg/roam-switch-to-personal-notes~ to do this instead would
switch the live session out from under you.

*** Only Emacs' own saves are indexed
~org-roam-db-autosync-mode~ hooks buffer saves, so anything that changes
files outside Emacs -- a git pull, or a script writing notes -- stays
invisible to search until an explicit ~org-roam-db-sync~.
